# 🎫 Customer Support Ticket Priority Prediction & Automated Assignment System

## 📌 Overview

The **Customer Support Ticket Priority Prediction & Automated Assignment System** is a Salesforce-based project that uses **Agentforce and Salesforce Flow** to automate customer support ticket prioritization and assignment.

The system analyzes customer support ticket information and classifies tickets into **High, Medium, or Low priority**. Based on the priority, it can automatically assign the appropriate support level and create an urgent handling task for high-priority tickets.

The project aims to reduce manual ticket management, identify critical customer issues faster, and improve support-team efficiency.

## 🛠️ Technologies Used

* **Salesforce**
* **Agentforce**
* **Salesforce Auto-Launched Flow**
* **Custom Salesforce Objects**
* **Salesforce Tasks**

## ⭐ Key Features

* Automatic ticket priority classification
* High, Medium, and Low priority handling
* Agentforce-based ticket analysis
* Automatic support assignment
* Urgent task creation for high-priority tickets
* Latest customer ticket retrieval
* SLA breach risk checking
* Conversational interaction through Agentforce

## 🔄 Workflow

```text
Customer Support Ticket
        ↓
Account Identification
        ↓
Latest Ticket Retrieval
        ↓
Ticket Description Analysis
        ↓
Priority Classification
        ↓
High / Medium / Low
        ↓
Support Assignment
        ↓
Urgent Task Creation
        ↓
Agentforce Response
```

## 📌 Project Phases


### **Phase 1: Requirement Analysis & Planning**

* Identified the customer support ticket prioritization problem.
* Analyzed user needs and support-team challenges.
* Defined functional and non-functional requirements.
* Designed the customer journey and data flow.
* Planned the Salesforce and Agentforce-based solution.

### **Phase 2: Salesforce Development – Backend & Configurations**

* Created and configured the Salesforce Developer Org.
* Designed the **Support Ticket Intelligence** custom object.
* Configured the **Auto-Launched Flow** for ticket analysis and automation.
* Created and configured the **Agentforce Support Ticket Priority Analysis** subagent.
* Integrated Agentforce with the Salesforce Flow.
* Tested ticket priority classification, assignment, and urgent-task creation.
